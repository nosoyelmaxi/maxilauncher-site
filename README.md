# MaxiLauncher Public Website

This repository contains the public informational website for **MaxiLauncher**, an independent Windows desktop launcher for Minecraft: Java Edition focused on managed modded instances and modpacks.

The launcher source code is maintained separately in a private development repository while the project is under active development.

## Purpose of this site

This public page provides basic information about MaxiLauncher for users, service providers and application-review processes, including:

- the purpose of the launcher;
- Microsoft account authentication approach;
- Minecraft ownership requirements;
- current technical scope;
- project status;
- developer contact/reference information.

## Important

MaxiLauncher is an independent project and is not affiliated with, endorsed by, or sponsored by Microsoft, Mojang Studios, Xbox or Fabric.
