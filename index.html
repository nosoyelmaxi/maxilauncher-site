MaxiLauncher

MaxiLauncher is an independent Windows desktop launcher for Minecraft: Java Edition. It is designed to let legitimate Minecraft owners authenticate with their own Microsoft account and launch managed Minecraft instances and modpacks without manually configuring every dependency.

Official account authentication

MaxiLauncher uses Microsoft's official OAuth 2.0 authorization flow and the standard Xbox Live, XSTS and Minecraft Services authentication chain. The launcher does not ask users to enter their Microsoft password into MaxiLauncher itself.

Managed Minecraft instances

The project is being built to manage Minecraft versions, Java requirements, Fabric, mods and instance-specific configuration from one desktop application.

Ownership is required

MaxiLauncher is not intended to bypass Minecraft ownership checks, account licensing, Microsoft authentication or Minecraft Services. Users must authenticate with an eligible Microsoft account that owns or is entitled to Minecraft: Java Edition.

Authentication purpose

The requested Microsoft/Minecraft authentication access is used only to complete the official sign-in chain, validate the Minecraft account/profile required for game launch, maintain an authenticated session, and start Minecraft for the signed-in user. MaxiLauncher does not use Microsoft authentication to provide cracked/offline access or to bypass game entitlement checks.

Project status

MaxiLauncher is currently in early development. The technical core is being validated first, including authentication, Java management, Fabric-based test instances, file validation and managed updates. A final user interface and public distribution workflow will follow after the core launcher has been validated.

Current technical scope

  • Windows desktop application built with Electron.
  • Microsoft OAuth authentication for legitimate Minecraft accounts.
  • Minecraft: Java Edition instance management.
  • Fabric and modded-instance support.
  • Managed distribution and repair of declared instance files.
  • Separate handling of launcher updates and modpack/instance updates.

Privacy and credentials

MaxiLauncher does not require users to provide their Microsoft password directly to the application. Authentication takes place through Microsoft's authorization interface. The project does not publish or intentionally collect user passwords, client secrets or private account credentials through this website.
