Privacy notice

Last updated: October 2026.

MaxiLauncher is currently in active development. This notice describes the intended handling of account information by the desktop launcher and this public project website.

Microsoft authentication

MaxiLauncher uses Microsoft's OAuth authorization interface. Users authenticate on Microsoft's own sign-in pages; MaxiLauncher is not designed to collect a user's Microsoft password.

Account data used by the launcher

To launch Minecraft: Java Edition for an authenticated user, the launcher may process the authorization tokens and Minecraft profile information required by Microsoft, Xbox Live and Minecraft Services. These values are used for authentication, entitlement/profile validation, token refresh and game launch functionality.

Local storage

Account session information required by the desktop launcher may be stored locally on the user's computer so that the user does not need to authenticate on every launch. MaxiLauncher does not operate a public account database or authentication backend at this stage of development.

This website

This GitHub Pages website is informational. It does not provide a sign-in form and does not request Microsoft passwords, access tokens or other private account credentials.

Third-party services

Authentication and Minecraft account services are provided by Microsoft, Xbox and Minecraft Services and remain subject to their respective terms and privacy practices. GitHub hosts this informational website through GitHub Pages.

Development status

Privacy and security behavior will continue to be reviewed as MaxiLauncher moves toward public distribution. This notice will be updated if the application's data handling materially changes.

MaxiLauncher is an independent project and is not affiliated with, endorsed by, or sponsored by Microsoft, Mojang Studios, Xbox or Fabric.
